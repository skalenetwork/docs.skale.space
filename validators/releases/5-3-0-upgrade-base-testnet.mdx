---
title: Upgrade to v5.3.0 on Base Sepolia Testnet
description: Upgrade SKALE validator nodes on Base Sepolia testnet with node version 5.3.0-base-testnet
---

This release updates the node version to `5.3.0-base-testnet`, node-cli to `3.3.1`, and SGXWallet to `1.10.4` on Base Sepolia testnet.

<Note>
Before starting, back up the SGXWallet `sgx_data` directory and `sgx_wallet_backup_key.txt` on another machine. Back up each node with `skale node backup .` from the directory containing its `.env` file.
</Note>

## Upgrade the SGX server

<Steps>
  <Step title="Set the SGXWallet image to v1.10.4">
    On the SGX server, open `sgxwallet/run_sgx/docker-compose.yml` and set the image to:

    ```yaml
    image: skalenetwork/sgxwallet:1.10.4
    ```

    Keep the existing volumes, devices, and command settings.
  </Step>

  <Step title="Restart SGXWallet with the new image">
    From `sgxwallet/run_sgx`, run:

    ```bash
    docker compose down && docker compose pull && docker compose up -d
    ```
  </Step>
</Steps>

## Upgrade each Base Sepolia testnet node server

<Steps>
  <Step title="Download node-cli v3.3.1">
    On each node server, download the Linux x86_64 binary:

    ```bash
    curl -fL https://github.com/skalenetwork/node-cli/releases/download/3.3.1/skale-3.3.1-Linux-x86_64 -o /usr/local/bin/skale
    ```
  </Step>

  <Step title="Verify the node-cli binary checksum">
    ```bash
    sha512sum /usr/local/bin/skale
    ```

    Expected checksum:

    ```text
    baa46bb22f535cef979cf8816ddefb0d0b51fec37129af6f5ec65774cfe609714ccaa2d656fd7962deb7c1f6e06df1ee637e2a5ff1fecc06539a672ebc7d27cd
    ```
  </Step>

  <Step title="Make node-cli executable">
    ```bash
    chmod +x /usr/local/bin/skale
    skale version
    ```
  </Step>

  <Step title="Set the SKALE node version">
    In the node's `.env` file, set:

    ```bash
    NODE_VERSION=5.3.0-base-testnet
    ```

    Keep the existing Base Sepolia testnet `ENDPOINT`, `ENV_TYPE`, contract addresses, and other network settings.
  </Step>

  <Step title="Run the node update">
    From the directory containing `.env`, run:

    ```bash
    skale node update .env --yes
    ```

    Then check the node and its SGXWallet connection:

    ```bash
    skale node info
    skale health sgx
    ```
  </Step>
</Steps>
